Strengths vs. Gaps
What's Working / What's Not
✓ Strength
Shopify Backend — Bulletproof
The platform itself is solid. Shopify handles hosting, SSL, CDN, and uptime. The rebuild is purely cosmetic — the backend stays untouched.
⚠ Critical Gap
Brand Name Mismatch in SEO
Page title still reads "Prints Supply" in several places. The rebrand to "Alabama Vinyl and Print Company" is not reflected in title tags, H1s, or schema markup.
✓ Strength
Local SEO Foundation Exists
Already ranking 3rd–4th locally for vinyl-related searches. GBP listing is live. Strong foundation to push to #1 with on-page fixes and schema.
⚠ Critical Gap
Broken Pages from Prior Contractor
Previous overseas contractor copy-pasted content including non-English text onto several pages. Multiple tabs still have mismatched or placeholder content.
✓ Strength
Drip Apps Gang Sheet Builder
The custom DTF upload app is already installed. It's misconfigured, but the infrastructure is there. Fix, don't rebuild.
⚠ Critical Gap
No Visual Brand Identity
The site uses the generic Impulse theme with minimal customization. No brand story, no visual hierarchy, no emotional connection. Looks like a template, not a brand.
✓ Strength
Distinctive Logo
The hound dog badge logo is memorable and has brand equity. It's a keeper — the rebuild will feature it prominently rather than bury it.
⚠ Gap
No DTF Customer Journey
Three distinct ordering flows exist (by size, gang sheet builder, pre-built upload) but there's no guidance for customers on which to choose. Leads to confusion and abandoned carts.
Technical Audit
Page-by-Page Findings
  • ✗
    Homepage H1 — Brand Name Mismatch H1 reads "Prints Supply" in several instances. Should be "Alabama Vinyl and Print Company." Affects local SEO ranking directly.
  • ✗
    Navigation — 10+ Items, No Hierarchy Main nav is overcrowded with 10+ links. No visual grouping, no mega-menu, no clear primary CTA. Customers can't find DTF ordering quickly.
  • ~
    DTF Product Pages — App Installed, Misconfigured Drip Apps gang sheet builder is live but the flow is unclear. Customers don't know which ordering method to use. Needs UX copy and flow redesign.
  • ✗
    Broken Content Pages — Prior Contractor Damage Several pages contain copy-pasted placeholder content, non-English text, and stock video from a reference site. Pages need full content audit and replacement.
  • ✗
    404 Page — Placeholder Product Showing 404 error page shows "EXAMPLE PRODUCT $29" — a default Shopify placeholder. Needs custom 404 with navigation back to shop.
  • ~
    Local Schema Markup — Incomplete No LocalBusiness schema. No structured data for address, hours, or phone. GBP listing exists but site schema doesn't reinforce it.
  • ✓
    SSL / HTTPS — Active Shopify-managed SSL certificate is active. No mixed content warnings observed.
  • ✓
    Mobile Responsive — Functional Impulse theme is mobile-responsive by default. Layout is functional on mobile, though not optimized for the DTF ordering flow on small screens.
  • ~
    Page Speed — Acceptable, Not Optimized Shopify CDN keeps baseline speed acceptable. No lazy loading on product images. No custom speed optimization applied.
Rebuild Priorities
What Gets Fixed First
Top Priority Items — Phase 1 of Rebuild
01
Fix brand name across all title tags, H1s, and meta descriptions Immediate SEO impact. "Alabama Vinyl and Print Company" must be consistent everywhere.
02
Rebuild navigation — 5 items max, clear hierarchy Shop, DTF Transfers, Ready-to-Press, About, Contact. Scalable slots for stickers/banners/promo items.
03
Rebuild homepage hero — bold, branded, dual CTA Black background, red accent, white text. "Order DTF Transfers" + "Browse Ready-to-Press." Above the fold, no scroll required.
04
Fix DTF customer journey — three flows, clearly labeled Transfers by Size / Build a Gang Sheet / Upload Your File. Each with a 1-sentence descriptor so customers self-select.
05
Add LocalBusiness schema + align with Google Business Profile Address, hours, phone, business name — all matching GBP exactly. Direct path to #1 local ranking.
